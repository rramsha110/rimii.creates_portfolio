SEO Services

SEO & Website Optimization

I handle SEO as part of a complete website build — from the initial technical and on-page foundation through ongoing monitoring and optimization.

01 · Initial SEO Foundation

One-Time SEO Setup

A complete initial optimization of the existing website to improve search-engine visibility and create a strong SEO foundation.

  • Complete website SEO audit
  • Keyword research relevant to the business
  • SEO-friendly page titles and meta descriptions
  • H1, H2 and H3 heading optimization
  • URL / slug optimization
  • Image ALT-text optimization
  • Internal linking between relevant pages
  • Sitemap and indexing setup / check
  • Google Search Console setup / check
  • Basic technical SEO checks
  • Mobile-friendliness and basic performance checks
  • On-page SEO improvements
  • Final SEO review after implementation
Typical timeline: 7–14 days depending on page count and implementation work.

Outcome: A properly optimized SEO foundation designed to improve visibility, indexing and search-engine understanding of the website.
02 · Ongoing Optimization

Monthly SEO Management

Optional ongoing management for continuous optimization, monitoring and improvement of the website's search visibility.

  • Monitor website indexing and SEO health
  • Keyword and search-performance monitoring
  • Update existing pages where required
  • On-page SEO improvements
  • Internal linking improvements
  • Image / ALT-text optimization where required
  • Basic technical SEO checks
  • Google Search Console monitoring
  • Identify new SEO opportunities
  • Monthly SEO update / report
Recommended approach: SEO is an ongoing process. After the initial foundation, the service can be continued, paused or cancelled according to the client's requirements.
Scope: SEO optimization and monitoring of the existing website. Major website changes, new pages, extensive content writing, blog creation, backlink campaigns, paid advertising or other work outside the listed services can be discussed separately if required.

SEO is treated as continuous improvement based on website performance and search data.
